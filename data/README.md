# Dataset notes

The project report refers to a retail transaction dataset named `retail_big.csv`; the screenshot shows it stored in HDFS at `/retail/input/` with a size of approximately 520.1 MB.

The CSV is not included in this ZIP. Before publishing it, check its source, license, and whether redistribution is permitted. A dataset of this size may be better hosted separately with instructions for obtaining it.

The Hive script assumes example column names. Verify them against the real CSV before running the queries.
